# 企业图谱实体关系清单

## 1. 实体清单
| 实体 | 说明 | 关键属性 |
|---|---|---|
| 企业 | 图谱核心对象 | 名称、简介、成立时间、融资阶段、官网 |
| 行业/赛道 | 企业所属方向 | 名称、上级分类 |
| 产业链环节 | 企业所在链条位置 | 名称、上游、下游 |
| 产品 | 企业对外产品 | 名称、类别 |
| 技术 | 企业技术能力 | 名称、类型 |
| 能力标签 | 企业能力抽象标签 | 标签名 |
| 地区 | 企业所在区域 | 省、市、区 |
| 融资事件 | 企业融资记录 | 时间、轮次、金额 |
| 机构 | 投资机构或合作机构 | 名称、类型 |
| 需求标签 | 企业需求分类 | 标签名、优先级 |

## 2. 关系清单
| 起点 | 关系 | 终点 | 说明 |
|---|---|---|---|
| 企业 | 属于 | 行业/赛道 | 企业所属领域 |
| 企业 | 处于 | 产业链环节 | 企业在链条中的位置 |
| 企业 | 提供 | 产品 | 企业对外产品 |
| 企业 | 掌握 | 技术 | 企业掌握的技术 |
| 企业 | 具备 | 能力标签 | 企业能力抽象 |
| 企业 | 位于 | 地区 | 企业区域信息 |
| 企业 | 发生 | 融资事件 | 企业融资记录 |
| 融资事件 | 投资方 | 机构 | 投资机构关系 |
| 企业 | 提出 | 需求标签 | 当前服务需求 |

## 3. 最小字段建议
### 企业
- enterprise_id
- enterprise_name
- short_intro
- industry
- stage
- location

### 需求标签
- demand_tag
- demand_type
- priority

### 融资事件
- round
- date
- amount
