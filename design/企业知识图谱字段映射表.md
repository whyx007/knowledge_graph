# 企业知识图谱字段映射表

## 1. 节点类型定义
| 节点类型 | 说明 |
|---|---|
| Enterprise | 企业 |
| Product | 产品 |
| Capability | 技术/能力 |
| Industry | 行业/应用行业 |
| Scenario | 应用场景 |
| Customer | 客户 |
| Supplier | 供应商 |
| DemandTag | 需求标签 |

## 2. 关系类型定义
| 关系类型 | 含义 |
|---|---|
| PROVIDES_PRODUCT | 企业提供产品 |
| HAS_CAPABILITY | 企业具备能力 |
| SERVES_INDUSTRY | 企业服务行业 |
| APPLIES_TO_SCENARIO | 企业应用于场景 |
| HAS_CUSTOMER | 企业拥有客户 |
| HAS_SUPPLIER | 企业拥有供应商 |
| HAS_DEMAND | 企业存在需求 |

## 3. Excel字段映射
| 原始字段 | 目标对象 | 存储方式 |
|---|---|---|
| 公司名称 | Enterprise.enterprise_name | 企业节点主键字段 |
| 企业简介/一句话介绍 | Enterprise.intro | 企业属性 |
| 产品 | Product | 节点 + 关系 |
| 客户 | Customer | 节点 + 关系 |
| 供应商 | Supplier | 节点 + 关系 |
| 核心能力/技术 | Capability | 节点 + 关系 |
| 产品应用行业 | Industry | 节点 + 关系 |
| 应用场景 | Scenario | 节点 + 关系 |
| 商业模式 | Enterprise.business_model | 企业属性 |
| 认证/资质/知识产权 | Enterprise.certification_ip | 企业属性 |
| 创始团队/团队背景 | Enterprise.founder_team | 企业属性 |
| 当前最需要资源/需求 | DemandTag | 节点 + 关系 |
| 营收/融资/经营情况 | Enterprise.revenue_financing | 企业属性 |
| 竞争优势/亮点/补充说明 | Enterprise.advantage | 企业属性 |
| 匹配度 | Enterprise.match_level | 企业属性 |
