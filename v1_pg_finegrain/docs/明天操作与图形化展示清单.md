## 5. 最适合图形化展示的查询

### 5.1 某企业在主图谱中的位置
```cypher
MATCH (e:Enterprise {name: '中科慧远视觉技术（洛阳）有限公司'})
OPTIONAL MATCH (e)-[r1:FOCUSES_ON_SUB_TRACK]->(s:SubTrack)
OPTIONAL MATCH (e)-[r2:LOCATED_IN_STAGE]->(st:ChainStage)
OPTIONAL MATCH (e)-[r3:HAS_KEY_CAPABILITY]->(k:KeyCapability)
RETURN e, r1, s, r2, st, r3, k;
```

### 5.2 解释链：关键能力 -> 技术方向 -> 环节
```cypher
MATCH (k:KeyCapability)-[r1:SUPPORTED_BY]->(t:TechDirection)
MATCH (t)-[r2:ENABLES_STAGE]->(st:ChainStage)
WHERE k.id IN ['KCAP_MV_001','KCAP_OC_001','KCAP_LA_002']
RETURN k, r1, t, r2, st;
```

### 5.3 商业航天候选域结构图
```cypher
MATCH (s:SubTrack {id:'SUB_SPACE_001'})-[r1:HAS_STAGE]->(st:ChainStage)
OPTIONAL MATCH (st)-[r2:REQUIRES_CAPABILITY]->(k:KeyCapability)
WHERE k.id STARTS WITH 'KCAP_SPACE_'
OPTIONAL MATCH (t:TechDirection)-[r3:ENABLES_STAGE]->(st)
WHERE t.id STARTS WITH 'TD_SPACE_'
RETURN s, r1, st, r2, k, r3, t;
```

### 5.4 商业航天候选企业挂接图
```cypher
MATCH (e:Enterprise)-[r1:FOCUSES_ON_SUB_TRACK]->(s:SubTrack {id:'SUB_SPACE_001'})
OPTIONAL MATCH (e)-[r2:LOCATED_IN_STAGE]->(st:ChainStage)
WHERE st.id STARTS WITH 'STG_SPACE_'
OPTIONAL MATCH (e)-[r3:HAS_KEY_CAPABILITY]->(k:KeyCapability)
WHERE k.id STARTS WITH 'KCAP_SPACE_'
RETURN e, r1, s, r2, st, r3, k;
```

## 6. 明天展示时最容易踩的坑

必须加：
- `SUB_SPACE_001`
- `STG_SPACE_*`
