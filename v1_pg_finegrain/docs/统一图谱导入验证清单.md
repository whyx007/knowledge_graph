## 5. 当前风险点
### 风险1：本地 `LOAD CSV` 文件权限
若报错，优先检查：
- import 目录路径是否正确
- `dbms.security.allow_csv_import_from_file_urls` 是否需要打开
- DBMS 是否需要重启

### 风险2：旧 Enterprise ID 与当前本地库不一致
当前统一企业挂接关系使用的是 `E001` 这套 ID。
如果本地导入的 Enterprise 节点不是这一套 ID，而是 `ENT_xxx` 这种旧 ID，则企业挂接关系会导不进去。

这件事是当前最需要现场验证的点。

### 风险3：B 映射层只是首版样板映射
不应把当前 `MAPPED_TO` 结果当作全量映射完成版。

---

## 6. 最关键结论
当前最值得先验证的一件事不是结构关系，而是：

> **本地 Neo4j 的 Enterprise 主键，是否已经切换成了 `E001` 这套统一企业 ID。**

如果没有切换，就需要先补一层：
- `old Enterprise id` -> `E001` 映射
或
- 改写 `unified_rel_enterprise_to_*.csv`

否则结构关系都能导，唯独企业挂接会失效。
