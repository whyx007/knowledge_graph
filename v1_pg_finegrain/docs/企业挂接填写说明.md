# 企业挂接填写说明

## 1. 目的
本说明用于配套以下 4 张映射表：
- `data/mappings/三条产业链_环节清单.csv`
- `data/mappings/企业-子赛道映射表.csv`
- `data/mappings/企业-产业链环节映射表.csv`
- `data/mappings/企业能力-关键能力映射表.csv`

目标是把企业从“企业信息表”逐步挂接到三条客观产业链上。

---

## 2. 推荐填写顺序
建议严格按以下顺序填写：

### 第一步：先看标准环节清单
先打开：
- `三条产业链_环节清单.csv`

作用：
- 确认每个子赛道有哪些标准环节
- 避免不同人各写各的环节名

---

### 第二步：填写企业-子赛道映射表
再填写：
- `企业-子赛道映射表.csv`

要回答的问题：
- 这个企业主要属于哪条子赛道？
- 是否同时涉及第二条子赛道？

判断依据建议优先看：
1. 企业主营产品
2. 企业核心技术
3. 企业下游客户/场景
4. 企业公开介绍中的关键词

---

### 第三步：填写企业-产业链环节映射表
再填写：
- `企业-产业链环节映射表.csv`

要回答的问题：
- 企业位于这条产业链的哪个主环节？
- 是否跨多个环节？

判断原则：
- 优先看主营产品与交付形态
- 不要仅根据“行业大词”判断
- 一个企业可以多环节，但必须先定主环节

---

### 第四步：填写企业能力-关键能力映射表
最后填写：
- `企业能力-关键能力映射表.csv`

要回答的问题：
- 企业原始能力描述，对应到哪个标准关键能力？
- 这个能力支撑哪个环节？
- 有没有真实交付证据？

---

## 3. 实操建议

### 3.1 先粗挂，再细化
建议先完成：
- 子赛道
- 主环节

再做：
- 次环节
- 能力映射
- 证据校验

不要一开始就追求百分之百精细。

### 3.2 保留原始判断依据
每张表都保留 `judgement_basis` / `mapping_basis`，不要只写结论。

因为后面复核时，最重要的是知道“当时为什么这么判”。

### 3.3 置信度不要滥填高分
建议参考：
- 0.9~1.0：公开资料非常清晰，且有明确产品/案例支撑
- 0.7~0.8：基本明确，但有少量口径不确定
- 0.5~0.6：只能初判，需要复核
- 0.0~0.4：信息不足，不建议直接确认

### 3.4 优先保证主环节准确
即使次环节暂时不完整，只要主环节准确，图谱第一版就能先跑起来。

---

## 4. 一个简单例子
如果一家企业：
- 做高速光模块
- 介绍里强调封装、测试、量产交付
- 客户面向数据中心网络

那么更合理的填写方式是：
- 主子赛道：光通信/光模块
- 主环节：模块封装组装 或 模块测试校准 或 批量制造交付（根据主营强调点再细分）
- 关键能力：封装良率控制能力 / 高速测试能力 / 规模制造与交付能力

而不是只写：
- “属于光模块行业”

---

## 5. 当前最建议的推进方式
建议先选 20~30 家企业样本，按以下节奏推进：
1. 先完成子赛道归类
2. 再完成主环节挂接
3. 最后补能力映射

优先顺序建议：
1. 光通信 / 光模块
2. 光学检测 / 机器视觉
3. 激光加工 / 光学装备

因为第一条链当前口径最容易先做稳。
