# 产业链图谱实体关系清单

## 1. 实体清单
| 实体 | 说明 | 关键属性 |
|---|---|---|
| 产业 | 一级产业主题 | 名称、描述 |
| 子赛道 | 产业下细分方向 | 名称、上级产业 |
| 产业链环节 | 链条中的功能位置 | 名称、层级 |
| 技术方向 | 支撑环节的技术主题 | 名称、说明 |
| 关键能力 | 完成该环节所需能力 | 名称、类型 |
| 应用场景 | 下游应用方向 | 名称、行业 |
| 企业 | 代表企业/样本企业 | 名称、类型 |

## 2. 关系清单
| 起点 | 关系 | 终点 | 说明 |
|---|---|---|---|
| 产业 | 包含 | 子赛道 | 产业细分结构 |
| 子赛道 | 包含 | 产业链环节 | 赛道下的链条结构 |
| 产业链环节 | 上游依赖 | 产业链环节 | 上游输入关系 |
| 产业链环节 | 下游流向 | 产业链环节 | 下游输出关系 |
| 技术方向 | 支撑 | 产业链环节 | 技术支撑关系 |
| 产业链环节 | 需要 | 关键能力 | 所需能力 |
| 应用场景 | 拉动 | 产业链环节 | 场景需求牵引 |
| 产业链环节 | 代表企业 | 企业 | 典型参与者 |

## 3. 最小字段建议
### 产业链环节
- chain_stage_id
- chain_stage_name
- parent_track
- upstream_stage
- downstream_stage

### 技术方向
- tech_direction
- description

### 关键能力
- capability_name
- capability_type
