# 统一图谱查询说明

## 1. 目的
本说明对应：
- `neo4j/query_templates_unified_graph.cypher`

用于把当前 Neo4j 查询方式，从“企业图谱单视角”升级到“统一图谱双视角查询”。

---

## 2. 当前支持的统一查询方向

### 2.1 按子赛道看企业
适合回答：
- 这条样板链里纳入了哪些企业？
- 某条子赛道当前覆盖情况如何？

### 2.2 按环节找企业
适合回答：
- 某个环节有哪些被投企业/候选企业？
- 哪个环节当前企业覆盖最少？

### 2.3 看某企业在产业链中的位置
适合回答：
- 这家企业属于哪条子赛道？
- 这家企业主要处于哪一个环节？
- 它具备哪些统一关键能力？

### 2.4 从能力反查企业与环节
适合回答：
- 哪些企业具备某类关键能力？
- 某项能力在产业链哪个环节集中？

### 2.5 从场景反查企业与环节
适合回答：
- 某个应用场景会驱动哪些产业链环节？
- 这些环节上有哪些企业？

---

## 3. 建议先设置的参数
在 Neo4j Browser 中建议先设置：

```cypher
:param subTrackId => 'SUB_001';
:param stageId => 'STG_MV_008';
:param enterpriseName => '中科慧远视觉技术（洛阳）有限公司';
:param capabilityKeyword => '检测';
:param scenarioKeyword => '锂电';
:param limit => 20;
```

可按演示对象修改。

---

## 4. 建议演示顺序

### 第一步：先看子赛道覆盖
使用“查看所有子赛道与企业数量”或“按子赛道看企业”。

意义：
- 先让听众理解统一图谱已经不只是企业库
- 已经形成了可按子赛道管理的产业结构

### 第二步：再看环节分布
使用“按环节找企业”。

意义：
- 直接体现产业链视角
- 能看出企业位于链条哪里

### 第三步：再看单企业位置
使用“查看某企业在统一图谱中的位置”。

意义：
- 展示企业视角与产业链视角如何在一张图上统一

### 第四步：再看能力反查/场景反查
使用“从关键能力反查企业与环节”“从场景反查环节与企业”。

意义：
- 这是后续做推荐、寻源、匹配的基础

---

## 5. 当前统一查询与旧查询的差异

### 旧查询
主要回答：
- 企业有什么产品/能力/行业/场景标签

### 新查询
可以进一步回答：
- 企业位于哪条子赛道
- 企业位于哪个环节
- 这个环节需要什么关键能力
- 某个场景会驱动哪些环节
- 某个能力在哪些企业/环节上体现

一句话：

> 旧查询偏企业画像，新查询开始具备产业链结构化分析能力。

---

## 6. 当前限制
目前统一查询已经能跑通主链路，但仍有 3 个边界：

1. `Capability -> KeyCapability` 映射层还未系统补齐
2. `Scenario -> ApplicationScenario` 映射层还未系统补齐
3. 当前样板企业数量仍较少，更适合原型演示，不适合做大样本统计结论
