# 九维光子科技（昆山）有限公司挂链复核结论（2026-05-13）

## 1. 复核背景
原扩展 patch 中，九维光子科技（昆山）有限公司被挂到“光计算”赛道：
- 子赛道：SUB_005 光计算
- 环节：STG_005_002 光计算核心器件、STG_005_004 高速互连与封装模块
- 能力：KCAP_COMP_001 光计算芯片架构设计能力、KCAP_COMP_002 高速光互连集成能力

但根据本轮人工复核口径，企业更符合“特种光纤/无源光器件/医疗激光传能光纤/光纤传感底层器件”方向，不宜继续保留为“光计算”主挂。

## 2. 本轮复核结论
### 2.1 主挂子赛道
- 主挂：SUB_002 光通信 / 光模块

### 2.2 主环节
- 主环节：STG_OC_003 无源器件
- 次环节：STG_OC_004 结构件 / 材料

### 2.3 关键能力
- 主能力：KCAP_OC_002 光器件集成能力

## 3. 复核判断依据
1. 企业核心产品和能力更接近特种光纤、保偏光纤、医用激光传能光纤、无源光器件；
2. 在当前统一图谱已定义赛道中，“光通信 / 光模块”比“光计算”更能承载其上游器件与材料属性；
3. “激光加工 / 光学装备”更偏加工设备、激光器、执行单元与整机装备，不适合作为该企业主挂；
4. 医疗激光、光纤传感可作为应用延伸说明，但当前不单独作为主赛道。
