# 一、30秒版本（极简开场）

今天这套统一图谱，重点不是证明我们“能存企业”，而是证明三件事：

1. 我们已经有 3 条正式核心样板链跑通了；
2. 企业、能力、技术方向、产业链环节已经能串成解释链；
3. 商业航天已经完成候选域验证，可以作为 V2 扩展域受控纳入。

一句话概括就是：

> 统一图谱已经从“原型想法”走到了“主干可用、扩展可控、可进入 V2 范围决策”的状态。

# 二、1分钟版本（管理层快讲）

我们这次不是在做一个普通企业库，而是在做一套统一图谱底座。

当前正式跑通的有 3 条核心样板链：
- 光学检测 / 机器视觉
- 光通信 / 光模块
- 激光加工 / 光学装备

这三条链已经完成了：
- 主数据建模
- 结构关系补齐
- 企业挂接
- 技术方向、关键能力和产业链环节的解释链验证

在这个基础上，我们又把商业航天作为扩展候选域做了独立 patch 验证，已经证明：
- 结构可入图
- 企业可挂接
- 查询可跑通
- 但成熟度暂时还低于正式主干

所以 V2 的建议不是平铺范围，而是：

> 采用“3条正式核心域 + 1条商业航天扩展候选域 + 其他储备方向”的分层推进方式。

# 三、3分钟版本（标准演示版）

## 第一步：先讲这次要证明什么
今天演示不是想证明图数据库本身，而是想证明统一图谱已经形成了一个稳定主干，并且具备扩展新产业域的能力。

我们重点证明三件事：
1. 正式主干已经稳定；
2. 解释链已经跑通；
3. 商业航天扩展域已经验证成功。

---

## 第二步：先讲范围分层
先不看企业，先看范围治理。

统一图谱 V2 我们建议按三层管理：
- A层：正式核心域
- B层：扩展候选域
- C层：研究储备域

当前 A层是 3 条正式样板链：
- 光学检测 / 机器视觉
- 光通信 / 光模块
- 激光加工 / 光学装备

B层当前是：
- 商业航天

这一步的重点是先把“范围可控”讲清楚，避免大家担心后面什么都往里塞。

---

## 第三步：展示正式核心域总览
现在进入主图谱查询。

先看所有正式子赛道和企业分布。

这里重点不是某一家企业，而是证明：
- 统一图谱主干已经有稳定结构；
- 企业已经不是散点，而是落在具体子赛道和环节里。

这一步讲法要尽量简单：

> 我们不是把企业堆成一个列表，而是已经把企业放进产业链结构里看。

---

## 第四步：展示单企业位置
接下来挑一家公司看。

推荐示例：
- 中科慧远视觉技术（洛阳）有限公司

重点看三件事：
- 它属于哪条子赛道；
- 它位于哪个产业链环节；
- 它具备哪些关键能力。

这一步要让大家看到：
企业视角和产业链视角已经接在一张图上，而不是两套孤立表。

---

## 第五步：讲解释链
这是整场最关键的一段。

我们现在已经不是只会查“企业标签”，而是开始具备解释链。

现有链路包括：
- Capability -> DERIVES_FROM -> TechDirection
- KeyCapability -> SUPPORTED_BY -> TechDirection
- TechDirection -> ENABLES_STAGE -> ChainStage
- Enterprise -> HAS_KEY_CAPABILITY -> KeyCapability

举例讲法：

某家企业具备“高精度加工控制能力”；
这类能力背后依托的是“精密驱动与微振动控制技术”；
这个技术方向支撑的是“振镜/加工头/执行单元”等环节；
所以我们后续做推荐时，不再只是因为词像，而是能给出结构化理由。

这一段一定要讲，因为这就是统一图谱区别于普通企业库的核心价值。

---

## 第六步：展示反查能力
接下来展示按环节或按能力反查企业。

这里的意义是告诉大家：
统一图谱不是只能看单企业，也已经能做：
- 按环节找企业
- 按关键能力找企业
- 按场景反查环节与企业

这一步其实就是在给后续：
- 需求推荐
- 协同推荐
- 寻源推荐
- 产业匹配

提前打底。

---

## 第七步：展示商业航天候选域
现在开始展示扩展候选域，但要明确说：

> 商业航天不是正式核心域，而是已经完成候选域验证的扩展方向。

先看候选域企业总览，再看按环节找候选企业。

这里一定要提醒：
商业航天查询必须按候选域 ID 过滤，否则会混入原有正式链关系。

这一段重点不是证明“商业航天已经成熟”，而是证明：
- 我们已经有能力安全扩展新产业方向；
- 扩展方式是独立 candidate patch；
- 不会破坏当前主图谱主线。

---

## 第八步：最后收束到 V2 结论
最后不要停在“查出来很多结果”，而要收束到版本结论：

统一图谱 V2 建议按“3+1+储备”推进：
- 3 条正式核心样板链
- 1 条商业航天扩展候选域
- 其他方向继续储备

最后一句建议可以直接说：

> 统一图谱当前已经具备 V2 推进条件，下一步重点不再是证明能不能建，而是如何基于这套底座进入更稳定的产品化验证。
