# Capability 映射正式版 v2 说明

文件：
- `data/mappings/unified_rel_capability_to_keycapability_v2.csv`

## 1. 这份文件是什么
这是在 `unified_rel_capability_to_keycapability.csv` 的基础上，补入一批**高置信 Capability 映射**后的扩充正式版。

它的目的不是一次性把所有旧 Capability 全部清洗完，而是：
- 先把高置信、可直接进入统一图谱的映射补进去
- 让统一查询和推荐能力在三条样板链上更完整
- 把低置信映射继续留给后续人工校准

---

## 2. 本次并入原则
本次新增映射优先采用：
- `confidence >= 0.80`
- 语义与统一 KeyCapability 对应关系明确
- 不需要额外引入新中间层

已并入的新增重点包括：
- 仿人光学成像 -> 成像方案设计能力
- 工业外观精密检测技术 -> 高精度检测算法能力
- 机器视觉 -> 高精度检测算法能力（注意口径仍偏宽）
- 红外热像技术 -> 成像方案设计能力
- COS测试机 -> 高速测试能力
- COC老化机 -> 封装良率控制能力
- 光路耦合机 -> 封装良率控制能力

---

## 3. 当前仍保留在候选层、未正式并入的类型
以下类型暂不建议直接正式并入，仍保留在候选表中：
- 0.80 以下的低置信芯片/工艺能力映射
- 语义过宽、可能需要拆层的能力
- 未来可能更适合映射到 TechDirection 的能力

典型如：
- 光谱分析探测芯片
- 晶体外延技术
- 高精度晶圆键合
- 通信光交换芯片
- 贴片机等
- 精密驱动技术
- 空间微振动控制技术

---

## 4. 与 v1 的关系
- `unified_rel_capability_to_keycapability.csv`：首版正式映射
- `unified_rel_capability_to_keycapability_v2.csv`：在 v1 基础上的高置信扩充版

建议后续：
- 如果继续导入验证，优先使用 v2
- 等下一轮人工复核后，再决定是否覆盖 v1 成为新的主文件

---

## 5. 一句话结论

> v2 不是全量终稿，而是“先把高置信映射吃进去”的正式扩充版。
