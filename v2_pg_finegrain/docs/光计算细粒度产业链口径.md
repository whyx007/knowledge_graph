# 光计算细粒度产业链口径

## 1. 定位

光计算是光电子域下的平级产业链，覆盖光计算芯片、光互连、光电混合计算和系统级平台。

## 2. 层级

```text
光计算
-> 上游：材料工艺、无源器件、有源器件、高速电芯片与封装
-> 中游：光计算芯片、光互连模块、系统集成、光电混合平台
-> 下游：AI算力、数据中心互连、HPC、网络通信与边缘计算
```

## 3. 边界

纳入硅光、薄膜铌酸锂、光调制器、光交换芯片、光I/O、CPO、光AI加速、数据中心光计算。

不纳入纯电子AI芯片、普通云计算软件、无光电硬件证据的数据中心服务。

## 4. 交叉关系

光计算与光通信在光模块、CPO、硅光、数据中心互联处交叉。光计算链强调计算和互连平台能力，光通信链强调通信传输链条。
