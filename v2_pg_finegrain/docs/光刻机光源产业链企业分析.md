# 光刻机光源产业链企业分析

> 查询日期：2026-06-30
> 聚焦：光刻机光源的上游元器件 + 中游整机集成
> 光源类型：DUV 准分子激光（248nm KrF / 193nm ArF）、EUV 激光等离子体光源（LPP）

---

## 产业链结构

```
上游元器件                中游整机集成              下游应用
────────────            ────────────              ──────
光学元件/镜片 ─┐
镀膜技术 ──────┤
激光芯片/晶体 ─┤
气体/电源 ─────┼──→ 准分子激光器 ──→ DUV 光刻机
特种材料 ──────┤    窄线宽激光器 ──→ 检测/量测
精密结构件 ────┘    超快激光器   ──→ EUV 驱动光源
                    EUV 光源系统 ──→ EUV 光刻机
```

## 关键发现

### 1. 广东卓劼激光 — 唯一准分子激光器企业

卓劼是国内极少数做准分子激光器的企业。全球 DUV 光刻光源市场被日本 Gigaphoton 和荷兰 Cymer(ASML) 垄断。卓劼的准分子激光器是国产替代的关键环节，但目前 Neo4j 中仅挂在通用"固体激光器/半导体激光器"环节，**未关联到光刻光源**。

### 2. 致微光学 — 光刻照明系统有产品但未挂光源环节

致微的产品描述中明确写"光刻机光学系统（曝光系统、照明系统）"，但当前仅挂在"半导体精密光学系统"（通用环节），未挂到 `SUB_LA_056` 光刻光源相关部件。

### 3. 西安科佳 (155) + 西安全谱红外 (402) — Neo4j 中完全空白

两家企业的 Enterprise 节点在 Neo4j 中存在，但**没有任何挂载关系**，属于遗漏。
