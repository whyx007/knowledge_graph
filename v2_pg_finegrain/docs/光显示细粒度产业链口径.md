# 光显示细粒度产业链口径

## 1. 定位

光显示是光电子域下的平级产业链，不从属于光通信、激光加工或机器视觉。

## 2. 层级

```text
光显示
-> 上游：显示材料、显示芯片、驱动背板、光学结构件
-> 中游：封装键合、模组集成、整机系统、检测修复装备
-> 下游：消费电子、AR/VR、车载工业显示、商显和特种显示
```

## 3. 边界

纳入 Micro LED、Micro OLED、LCOS/DLP、Mini LED、量子点显示、AR光机、HUD、显示检测与修复装备。

不纳入普通显示屏贸易、纯内容服务、无显示硬件能力的终端应用公司。

## 4. 交叉关系

面板检测和像素检测可与机器视觉交叉；激光修复和巨量转移装备可与激光加工交叉。企业挂接时按产品证据可多链挂接。
