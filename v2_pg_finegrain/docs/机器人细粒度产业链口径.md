# 机器人细粒度产业链口径

## 1. 定位

机器人是新版细粒度模型中的平级候选产业链，归属 `先进制造` 域。它不从属于光学检测/机器视觉或激光加工/光学装备，但与两者存在明确交叉。

## 2. 层级

```text
机器人
-> 上游：控制器、伺服、减速器、传感器、视觉感知、末端执行器、电源、软件算法
-> 中游：工业机器人、协作机器人、移动机器人、人形机器人、服务机器人、特种机器人、系统集成、平台服务
-> 下游：汽车、3C、新能源、半导体、仓储物流、医疗康养、商业家庭、巡检安防与特种作业
```

## 3. 边界

纳入：

- 机器人核心零部件
- 机器人本体
- 机器人系统集成
- 机器人调度和运维平台
- 机器人下游应用场景

不纳入：

- 只有普通自动化设备但无机器人本体或机器人集成证据的企业
- 只有机器视觉算法但无机器人应用证据的企业
- 只有激光设备但无机器人集成或机器人作业证据的企业
- 泛AI软件但无机器人控制感知或调度落地证据的企业

## 4. 与其他链的关系

与光学检测/机器视觉：

- 机器人视觉、3D视觉、视觉引导属于两条链的交叉点。
- 如果企业只做机器视觉系统，优先挂机器视觉链。
- 如果企业明确做机器人抓取定位、机器人视觉引导，可同时挂机器人链。

与激光加工/光学装备：

- 机器人激光焊接、机器人切割、机器人打磨等属于交叉场景。
- 如果企业只做激光设备，优先挂激光链。
- 如果企业提供机器人激光工作站或自动化单元，可挂机器人系统集成。

## 5. 当前成熟度

当前设为 `candidate`。完成候选挂接复核和业务确认后，可升级为正式平级链。
