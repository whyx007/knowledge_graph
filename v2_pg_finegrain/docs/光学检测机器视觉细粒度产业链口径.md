# 光学检测/机器视觉细粒度产业链口径

## 1. 定位

光学检测/机器视觉是新版细粒度模型中的平级产业链，与光通信/光模块、激光加工/光学装备等同级。

本链覆盖工业视觉核心部件、视觉算法平台、标准视觉系统、专用检测设备、3D视觉系统、整线检测方案，以及消费电子、半导体、面板、新能源、汽车、医药食品物流、机器人视觉等应用场景。

## 2. 层级

```text
光学检测/机器视觉
-> 上游：光源、镜头、工业相机、采集计算硬件、运动控制配套
-> 中游：算法平台、标准视觉系统、专用检测设备、3D视觉、整线方案、运维优化
-> 下游：消费电子、半导体、面板、汽车、新能源、医药食品物流、机器人视觉
```

## 3. 边界

纳入：

- 工业光源与照明控制
- 工业镜头、远心镜头、滤光片、成像模组
- 工业相机、图像传感器、高速相机、3D相机
- 图像采集卡、边缘计算、视觉控制器
- 视觉算法、OCR、缺陷检测、精密测量、视觉定位
- AOI、外观检测、在线检测、3D视觉系统
- 下游工业检测和机器人视觉引导场景

不纳入：

- 普通安防摄像头
- 消费级拍照模组
- 泛AI算法平台但无工业视觉落地证据
- 纯人工质检服务

## 4. 与其他链的关系

与激光加工/光学装备存在交叉：

- 激光装备可依赖视觉定位、在线检测、焊缝检测。
- 机器人激光加工可依赖机器人视觉引导。

与光显示存在交叉：

- 面板与显示检测可作为机器视觉下游应用。
- 显示材料、显示芯片、显示模组本体仍归光显示产业链。

与机器人存在交叉：

- 机器人本体和控制链条应归机器人产业链。
- 机器人视觉引导、抓取定位、装配视觉可归本链下游应用。
