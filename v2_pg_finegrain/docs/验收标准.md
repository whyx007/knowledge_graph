# 验收标准

## 1. 产业链结构验收

- 每条产业链作为独立 `IndustryChain` 管理，不依附于光通信/光模块。
- 每条产业链至少包含上游、中游、下游三个分段。
- 每个分段至少包含若干一级环节。
- 重点一级环节应继续拆到二级细分环节。

## 2. 光通信试点验收

- 光通信/光模块至少覆盖上游、中游、下游三段。
- 上游包含光芯片、光纤与预制材料、光学材料与封装材料、光电元器件。
- 中游包含有源光器件、无源光器件、光连接器与互连、光模块、CPO/光电共封装、WDM/OTN器件。
- 下游包含 5G/6G 基站光设备、数据中心光互联设备、光传输系统、行业应用。
- 每个一级环节至少有 2 个二级细分环节，除非业务确认该环节无需继续拆分。

## 3. 企业挂接验收

- 重点企业优先挂到二级细分环节。
- 企业挂接必须保留来源字段和置信度字段。
- 低置信挂接不能直接进入正式演示口径。
- 同一企业可挂多个产业链或多个环节，但必须有证据说明。

## 4. 数据源验收

- PostgreSQL 抽取结果不直接改 Neo4j。
- PostgreSQL 到 Neo4j 之间必须存在标准中间表。
- 中间表需要可重复生成，并保留抽取时间或版本号。

## 5. Neo4j 环境验收

- 新版 Neo4j Docker 端口不得与旧版冲突。
- 新版数据卷不得复用旧版数据卷。
- 新版导入脚本不得清理旧版数据库。

## 6. 查询验收

业务人员至少能查询：

- 某企业位于哪条产业链、哪个分段、哪个一级环节、哪个二级细分环节。
- 某个细分环节有哪些企业。
- 某条产业链从上游到下游的完整路径。
- 某企业上下游可能关联哪些环节。
- 哪些细分环节目前企业为空白或样本不足。
