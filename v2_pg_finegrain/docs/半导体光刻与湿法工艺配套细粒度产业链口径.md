# 半导体光刻与湿法工艺配套细粒度产业链口径

## 1. 定位

本链为候选产业链，用于承接现有光电子链条难以准确表达、但与光刻设备或晶圆制程直接配套的企业。

重点覆盖：

- 光刻曝光光路控制和精密执行部件
- 半导体湿法清洗、刻蚀、研磨抛光和剥离材料
- 单晶片湿法清洗、腐蚀、钝化等半导体工艺设备

## 2. 边界

纳入有明确半导体晶圆制程、光刻工序或光学曝光控制证据的材料、设备和核心部件。

不纳入普通金属表面处理、激光清洗、工业清洗剂、泛精密机械或无晶圆制程证据的材料设备。
