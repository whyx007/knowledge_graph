# 环境与连接信息

## 1. PostgreSQL

当前 PostgreSQL 与本工作区在同一台机器。

连接口径：

- 主机：`127.0.0.1` 或 `192.168.10.61`
- 端口：`5432`
- 数据库：`ceo_brief`
- 用户：`postgres`
- 企业表：`companies`，当前 480 家
- 学员表：`trainees`，当前 789 人
- 扩展：`pgvector v0.8.0`

连接串模板：

```text
postgresql://postgres:<password>@127.0.0.1:5432/ceo_brief
```

说明：密码不写入仓库文件。需要本地运行脚本时，通过环境变量 `PGPASSWORD` 传入。

- 局域网 Bolt：`bolt://192.168.10.61:7688`

- 密码：`neo4j2026`

端口映射：

```text
宿主机 7475 -> 容器 7474
宿主机 7688 -> 容器 7687
```

Docker 端口已绑定到 `0.0.0.0`，Neo4j advertised address 已配置为 `192.168.10.61`，同一局域网内机器可通过上述局域网地址访问。
