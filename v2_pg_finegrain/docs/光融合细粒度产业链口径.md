# 光融合（量子光学新原理）细粒度产业链口径

## 1. 定位

光融合是光电子域下的前沿候选平级产业链，覆盖量子光学、新原理成像、超灵敏探测和融合感知。

## 2. 层级

```text
光融合
-> 上游：量子光学材料器件、超灵敏感知器件、前沿光学芯片模组
-> 中游：新原理成像探测、融合感知控制、科研仪器装备
-> 下游：科研测量、生命科学成像、安防特种感知、工业复杂环境感知
```

## 3. 边界

纳入单光子、量子探测、弱光成像、偏振成像、光谱成像、量子光学实验平台、超快光谱和高端显微。

不纳入普通机器视觉、普通安防摄像头、普通科研耗材。

## 4. 成熟度

当前作为前沿候选链处理。候选企业挂接需要业务和技术专家复核后再升级为正式口径。
