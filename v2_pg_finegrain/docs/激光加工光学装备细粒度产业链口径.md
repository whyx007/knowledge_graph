# 激光加工/光学装备细粒度产业链口径

## 1. 定位

激光加工/光学装备是新版细粒度模型中的平级产业链，与光通信/光模块、光学检测/机器视觉、光显示、光计算、光融合、商业航天等同级。

本链覆盖激光加工、专用激光装备、金属增材制造、半导体光学装备与激光工艺装备。光刻机相关内容只覆盖光源、精密光学、检测量测和半导体激光工艺装备，不把光刻机整机产业链并入本链。

## 2. 边界

纳入：

- 激光器与激光源
- 光学器件与光路部件
- 执行单元与加工头
- 控制系统与工业软件
- 运动平台与精密机械
- 标准激光加工设备
- 高端/专用激光装备
- 激光3D打印/金属增材制造装备
- 半导体光学装备与激光工艺装备
- 下游金属加工、汽车、锂电、光伏、消费电子、半导体、医疗器械和高端制造应用

不纳入：

- 光刻机整机
- 光刻胶
- 涂胶显影 Track
- 掩膜版完整制造链
- 半导体前道设备完整产业链

## 3. 层级

```text
激光加工/光学装备
-> 上游：激光器、光学器件、加工头、控制系统、运动平台
-> 中游：标准设备、专用激光装备、自动化集成、整线交付、3D打印、半导体光学与激光工艺装备
-> 下游：金属加工、汽车、锂电光伏、消费电子、半导体、医疗器械与高端制造
```

## 4. 光刻机相关口径

本链只保留光刻相邻能力：

- 光刻光源相关部件
- 准分子/深紫外光源
- 半导体精密光学系统
- 掩膜版/晶圆光学检测设备
- 晶圆激光切割设备
- 晶圆激光打标设备
- 激光退火设备
- 半导体封装激光工艺设备

如果后续需要完整表达光刻机，应单独建设平级产业链：`半导体装备/光刻机产业链`。
