## 芯邺科技画像（基于公开信息）

| 项目 | 内容 |
|---|---|
| 位置 | 南京江北新区"芯片之城"科创基地三期 |
| 投资规模 | **4.1 亿元** |
| 业务定位 | **半导体芯片研发与制造**（前道+后道全流程） |
| 前道工艺 | 晶圆减薄（Wafer Thinning）、划片（Dicing）、贴装（Die Attach）、键合（Wire Bonding） |
| 后道工艺 | 塑封（Molding）、后固化（PMC）、电镀（Plating）、激光打标/印刷、切筋成型（Trim/Form） |
| 招聘方向 | 半导体封测厂前道/后道工艺工程师（要求2年+经验） |
| 人员规模 | 正在大规模招聘中（含猎头渠道），推测产线筹建/爬坡阶段 |

**判断**：芯邺正在建设一条**中道+后道半导体封装产线**，覆盖从晶圆级加工到成品封测的完整流程。4.1亿元投资规模指向中等批量、多品种的封测服务能力。

### 🔴 第一梯队：核心耗材供应商

#### 4. 北京序轮科技 (ENT_PG_224) — 晶圆划片膜/贴装胶膜

| 维度 | 内容 |
|---|---|
| 所在地 | 北京 |
| 产品 | **UV减粘膜（晶圆UV划片膜）**、**DAF膜（切割型芯片贴装胶膜）**、ABF堆积膜、高分子弹性膜运载盒 |
| 与芯邺的匹配 | ⭐⭐⭐⭐⭐ **UV减粘膜=晶圆划片工序必需耗材**，DAF膜=贴装工序必需耗材 |
| Neo4j 状态 | ✅ 已入库 |
| 合作路径 | ① UV减粘膜 → 芯邺划片工位 ② DAF膜 → 芯邺贴装工位 |

**分析**：这是最直接的耗材供应关系——芯邺每划一片晶圆就需要消耗UV膜，每次贴装就需要DAF膜。序轮的半导体制程特种高分子材料是芯邺产线的**持续性消耗品**。

| 与芯邺的匹配 | ⭐⭐⭐⭐ 塑封（Molding）和封装散热需要封装材料和导热材料 |

## 下游合作机会 — Neo4j 企业可用芯邺封测服务的

### 🔴 第一梯队：高匹配度 Chiplet / 先进封装需求方

#### 1. 英伟芯（西安）(ENT_PG_63) — 晶圆级异构集成

| 维度 | 内容 |
|---|---|
| 需求 | 激光器晶圆 + 硅光晶圆 + CMOS 驱动芯片的**晶圆级混合键合**；3D-Packaged CPO；Optical I/O 模块封装 |
| 与芯邺的匹配 | ⭐⭐⭐⭐⭐ **英伟芯的晶圆级异构集成需要先进封装能力，芯邺的键合+塑封产线可承接** |
| 合作路径 | 英伟芯提供设计+晶圆 → 芯邺执行混合键合+封装 → 英伟芯交付 CPO 光引擎 |

**分析**：英伟芯的 3D-Packaged CPO 需要将化合物器件晶圆、硅光晶圆和 CMOS 晶圆做晶圆级键合——这正是物元半导体和芯邺可以协同提供的服务。如果芯邺具备混合键合能力，这是战略级合作。

#### 2. 物元半导体技术（青岛）(ENT_PG_13) — 互补型合作伙伴

| 维度 | 内容 |
|---|---|
| 产品 | 混合键合、WoW/CoW、Chiplet 异构集成**中道工艺** |
| 与芯邺的关系 | ⭐⭐⭐⭐ **中道+后道互补**：物元做中道（混合键合、晶圆级集成）→ 芯邺做后道（塑封/电镀/切筋成型/测试） |
| 合作路径 | 物元完成中道集成 → 交给芯邺做后道封装 → 交付出货 |

**分析**：这是上下游协同而非竞争——物元擅长前道/中道，芯邺强在后道，两家合在一起就是 Chiplet 先进封装的全流程。地理位置一南一北可互补。

#### 3. 原粒（北京）半导体 (ENT_PG_175) — AI 芯粒

| 维度 | 内容 |
|---|---|
| 产品 | 多芯粒大模型推理加速卡、AI Chiplet、算力模组 |
| 需求 | 多芯粒集成需要先进封装（2.5D interposer 或 3D stacking） |
| 与芯邺的匹配 | ⭐⭐⭐⭐ **Chiplet 产品的封测外包需求** |
| 合作路径 | 原粒设计 AI 芯粒 → 芯邺做多芯粒集成封装和测试 |

#### 4. 奇异摩尔（衢州）(ENT_PG_479) — Chiplet 设计+封测

| 维度 | 内容 |
|---|---|
| 产品 | 3D Chiplet 通用底座、Chiplet 设计+量产封测 |
| 与芯邺的关系 | ⭐⭐⭐ **竞合关系**：奇异摩尔自己也做封测，但如果产能不足或需要特定工艺，可外包给芯邺 |

## 最关键的三条合作路径

```
路径A（设备+耗材入厂）：
  广东阿达(焊线机/固晶机) + 北京序轮(UV膜/DAF膜) → 芯邺产线

路径B（Chiplet全流程联盟）：
  物元半导体(中道混合键合) → 芯邺(后道封装) → 英伟芯/原粒(Chiplet产品)

路径C（同城硅光封测）：
  希烽光电(硅光芯片设计) → 芯邺(光电封装) → 光模块/激光雷达市场
```
