# 商业航天细粒度产业链口径

## 1. 定位

商业航天是商业航天域下的平级产业链，覆盖卫星、火箭、地面系统、星座运营和下游应用。

## 2. 层级

```text
商业航天
-> 上游：卫星平台部组件、星载载荷、火箭动力、航天电子
-> 中游：整星制造、火箭发射、地面测运控、星座运营和数据平台
-> 下游：卫星通信、遥感应用、导航时空服务、空间试验与在轨服务
```

## 3. 边界

纳入商业卫星、商业火箭、星载载荷、地面站、遥感数据平台、卫星互联网、高精度定位和在轨验证。

不纳入传统军工航天完整体系、无商业化服务证据的科研项目、泛通信或泛遥感软件。

## 4. 交叉关系

商业航天与光通信在星地通信和卫星互联网处交叉，与光学检测/机器视觉在遥感影像处理和光学载荷处交叉，与机器人在空间在轨服务和特种作业处存在后续扩展空间。
