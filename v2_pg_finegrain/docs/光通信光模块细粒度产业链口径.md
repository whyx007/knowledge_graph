# 光通信/光模块细粒度产业链口径

## 1. 定位

光通信/光模块是新版细粒度模型的首个试点产业链。它与光学检测/机器视觉、激光加工/光学装备、光显示、光计算、光融合、商业航天等产业链平级。

本文件只定义光通信/光模块的样例口径，不代表其他产业链是其下属或补充。

## 2. 覆盖范围

覆盖从光通信材料、芯片、基础器件、光模块、光传输器件到通信网络和数据中心光互联设备的核心链条。

暂不展开：

- 普通消费光电子
- 通用半导体制造设备
- 泛电子元器件贸易
- 与光通信无明确关系的通信软件系统

## 3. 上游：材料、芯片、基础器件

### 光芯片

二级细分：

- 激光器芯片
- 探测器芯片
- 调制器芯片
- 硅光芯片
- 驱动/TIA芯片

纳入标准：

- 企业自研或量产光通信相关芯片。
- 企业产品明确用于光模块、光器件、光传输或数据中心光互联。

排除标准：

- 仅做普通集成电路设计且没有光通信应用证据。
- 仅做芯片代理销售。

### 光纤与预制材料

二级细分：

- 光纤预制棒
- 特种光纤
- 通信用光纤

纳入标准：

- 企业提供光通信传输用光纤、特种光纤或预制棒材料。

### 光学材料与封装材料

二级细分：

- 光学镀膜材料
- 陶瓷/金属/高分子封装材料
- 热管理材料

纳入标准：

- 材料明确用于光通信器件、模块封装或光学组件。

### 光电元器件

二级细分：

- 透镜/隔离器/准直器
- 光电转换元件
- 微光学组件

纳入标准：

- 企业产品进入光器件、光模块或光传输设备的关键组件链条。

## 6. 企业挂接规则

优先级：

1. 企业产品明确对应二级细分环节，挂到二级细分环节。
2. 企业描述只对应一级环节，先挂一级环节，并标记 `needs_review=true`。
3. 仅有行业标签但无产品或技术证据，不进入正式挂接表。

置信度：

- `high`：官网、产品手册、融资材料明确出现产品或技术。
- `medium`：业务描述可推断，但产品名称不完整。
- `low`：仅来自行业标签或泛化描述，需人工复核。
