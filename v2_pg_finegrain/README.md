# V2 PostgreSQL Fine-Grain Knowledge Graph Workspace

本目录用于建设新版投后产业服务知识图谱原型。

## 定位

- 旧版资产已整体迁入 `../v1_pg_finegrain/`，作为基线版本保留。
- 本目录面向新版 PostgreSQL 数据源、细粒度产业链建模和独立 Neo4j Docker 服务。
- 新版图谱不覆盖旧版 Neo4j 环境，先通过独立容器验证。

## 建设原则

1. 产业链平级管理：光通信/光模块只是首个试点，不是其他产业链的上级或补充。
2. 先离线闭环：PostgreSQL 先抽取为标准中间表，再导入 Neo4j。
3. 细粒度挂接：企业优先挂到二级细分环节，证据不足再降级到一级环节。
4. 不破坏旧环境：旧 Neo4j、旧 CSV、旧 Cypher 均不在本目录内直接修改。

## 目录说明

```text
docs/       产品方案、迁移方案、验收标准
design/     新版图谱模型和 PostgreSQL 数据口径
data/       标准中间表、映射表、导出结果
sql/        PostgreSQL 抽取视图模板
neo4j/      Docker、导入目录、Cypher 脚本
scripts/    后续抽取、校验、导入脚本
```

## 当前进展

已按同一细粒度模型建设：

- `光通信/光模块`
- `激光加工/光学装备`
- `光学检测/机器视觉`
- `机器人`

目标不是把某一条链做成唯一主线，而是验证统一方法：

`产业链 -> 上中下游分段 -> 一级环节 -> 二级细分环节 -> 企业`

验证通过后，光学检测/机器视觉、激光加工/光学装备、光显示、光计算、光融合、商业航天等产业链按同一层级、同一规则扩展。
