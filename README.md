# 投后产业服务知识图谱原型工作区

本工作区用于专门推进“投后产业服务知识图谱”原型。

## 当前范围
本期只做 2 个知识图谱：
1. 企业图谱
2. 产业链图谱

## 目标
围绕投后服务网站的知识能力建设，形成一个可评审、可演示、可迭代的知识图谱原型方案。

## 本工作区包含内容
- 产品方案与 PRD
- 双图谱范围定义
- 实体/关系设计
- 数据源与样例数据
- 演示查询与验收标准
- 后续研发对接输入

## 建议推进顺序
1. 明确业务场景与 MVP
2. 定义双图谱对象模型
3. 梳理数据源与样例数据
4. 设计关键查询/推荐路径
5. 准备原型演示材料
